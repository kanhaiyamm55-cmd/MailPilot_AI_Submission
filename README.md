
# MailPilot AI

### AI-Powered Email Management Dashboard

MailPilot AI is a modern, responsive email management dashboard prototype designed for personal assistants.

## Project Objective

The goal is to help personal assistants organize email conversations, identify important messages, understand who should respond, and focus client attention on decisions that require personal approval.

## Features

- Dashboard with email statistics
- Smart inbox with sample conversations
- Search emails by sender, subject, or content
- Filter emails by response responsibility
- Client Attention section
- AI-style email summaries and recommendations
- Suggested replies that users can edit
- Copy suggested replies
- Add sample emails
- Add demo email accounts
- Responsive mobile-friendly interface

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## How to Run

1. Keep all five files inside the same folder.
2. Open `index.html` in a web browser.
3. Navigate using the sidebar.
4. Open Smart Inbox to inspect sample emails.
5. Select an email to view its summary and suggested reply.
6. Try search, filters, and copy reply features.

## Important Prototype Limitations

This submission is a frontend prototype.

- Email accounts are demo accounts, not live connected inboxes.
- Sample emails are included for demonstration.
- AI-style summaries and classifications use predefined sample data.
- No real Gmail or Outlook OAuth integration is implemented.
- No real email sending or backend database is connected.

The prototype demonstrates the intended user experience and interaction flow. It is not a production email service.
